# シンキングツール 公開版

中学生向けの基本20種類のシンキングツールです。テーマ・図・メモ・まとめを編集し、PDF・PowerPoint・編集用JSONを端末に保存できます。

作品は各ツール1件ずつ、利用中のブラウザ内へ自動保存します。サーバーへ作品を同期する機能はありません。共有端末には氏名や成績などの個人情報を記入しないでください。PDF・PowerPointは画像による出力で、再編集にはJSONを利用します。

このリポジトリは配信用のアプリ本体のみを含みます。開発資料・認証情報・利用者の作品データは含みません。

元の思考ツール資料：https://ks-lab.net/haruo/thinking_tool/short.pdf

検証済みのアプリ f013c2e895508de5ef5a18ef30519cd9a6254619 を配置。単体74件、Windows Chrome・EdgeとLinux Chromiumで計192件の操作検証が成功しています。
