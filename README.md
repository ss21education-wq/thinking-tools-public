# シンキングツール 公開版

中学生向けの基本20種類のシンキングツールです。

公開URL：https://ss21education-wq.github.io/thinking-tools-public/

## キャンディチャート
同じキャンバスへ1～30組を追加・複製して、ハンドルで配置できます。条件・予想・理由・出所を1組で移動し、配置を保存。全画面での追加、選択削除、取り消し、全体表示に対応します。旧version 2/3のキャンディデータを引き継ぎ、新しい編集用JSONはversion 4です。

作品は利用中のブラウザ内へ自動保存します。サーバーへ作品を同期する機能はありません。共有端末では氏名・成績などを入力しないでください。PDF・PowerPointは画像による出力で、再編集にはJSONを利用します。以前のローカルファイルの保存内容は公開URLへ自動では移りません。

このリポジトリは配信用アプリだけを含み、開発資料・認証情報・利用者の作品データは含みません。

原資料：https://ks-lab.net/haruo/thinking_tool/short.pdf

単体77件、Windows Chrome・Edge／Linux Chromiumで各69件、計207件の操作検証が成功。各環境のPDF 25件・PPTX 24件も解析・描画検証済みです。

## 見やすさ・操作案内
通常の操作バーを横に動かせる1段にし、詳しい説明は「操作のヒント」にまとめました。「文字を読みやすく」で100%へ戻し、「画面を広く使う」で全画面へ切り替えます。ホームの見出し・文字色・押しやすさ・キーボードのフォーカス表示も調整しました。
検索は中点・空白・全角英数字の違いを吸収し、「クラゲチャート」「キャンディーチャート」「比較」でも探せます。作品の構造や保存方式は変更していません。

## データチャートのPDF
表の全行・全列と下部のまとめ（「この図から何が言える？」）を1ページに保存します。メモがあれば最下部に表示します。長文は文字サイズを調整し、それでも収まらない場合は入力を保持したまま保存時に案内します。2ページ目や省略はありません。PowerPointと他の図の出力は従来どおりです。

## クラゲチャートの足の操作
足の枠・上端をタップして選択し、Delete／Backspaceや上部バーのごみ箱で削除できます。文字編集中の削除キーは文字編集に使います。通常・全画面の上部バーと各足の上部から1本ずつ追加でき、選択した足の後へ追加してそのまま記入できます。削除・追加は取り消し可能で、通常画面でも足を削除したときの表示位置を保持します。

## Microsoft PowerPoint互換性の修正
PPTXにテーマ・プレゼンテーション設定・表示設定・表スタイルと対応する参照を追加しました。全ツールに適用します。修正した出力処理で生成した2枚の検証ファイルをMicrosoft PowerPoint本体で開き、両スライドの表示を確認しました。古いダウンロードファイルは、更新版のサイトから再出力してください。
